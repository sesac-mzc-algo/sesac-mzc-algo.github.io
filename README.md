# 🧩 코딩테스트 스터디 보드

주마다 알고리즘 주제를 자동으로 정하고, 그 주제에 맞는 문제 2개 + 랜덤 1개를 뽑아
멤버별 칸반(풀 문제 / 푸는 중 / 푼 문제)으로 관리하는 스터디 페이지.

**의존성 0개.** Node 22.5+ 내장 SQLite(`node:sqlite`)만 쓰므로 `npm install`이 필요 없습니다.

## 실행

```bash
node scripts/collect.js   # 문제 수집 (최초 1회, 1~2분)
node server.js            # http://localhost:3000
```

`npm start` / `npm run collect` 로도 동일하게 실행됩니다.
`data/study.db`에 이미 664개 문제가 수집돼 있으므로 바로 `node server.js`만 해도 됩니다.

### 환경변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `STUDY_INVITE_CODE` | (없음) | 설정하면 가입 시 초대 코드 필수 |
| `DB_PATH` | `data/study.db` | SQLite 파일 위치 |

## 계정

- 가입 화면에서 아이디/비밀번호만으로 계정 생성 (비밀번호는 scrypt 해시, 세션은 HttpOnly 쿠키).
- **첫 번째로 가입한 사람이 자동으로 관리자**가 됩니다.
- 외부에 열어둘 거라면 초대 코드를 켜세요: `STUDY_INVITE_CODE=우리스터디 node server.js`
- 새로 가입한 멤버에게는 기존 주차 문제도 자동 배정됩니다.

## 자동화

- 서버 시작 시 + 매시간, **이번 ISO 주차가 없으면 자동 생성**합니다. 별도 cron이 필요 없습니다.
- 주제는 `src/topics.js`의 커리큘럼 20개를 순환합니다 (해시 → 스택/큐 → 정렬 → … → 연결 리스트).
- 문제 3개 선정 규칙:
  1. **워밍업** — 주제에 맞는 프로그래머스 문제, 낮은 레벨 우선
  2. **본 문제** — 주제에 맞는 LeetCode 문제, Medium 우선
  3. **랜덤** — 주제 무관 1문제 (앞 두 문제가 다 Hard면 난이도를 낮춤)
- 이미 출제된 문제는 제외하고, 같은 문제가 두 출처로 겹치면(`N-Queen` / `N-Queens II`) 걸러냅니다.
- 같은 (연도, 주차)는 항상 같은 문제 세트가 나옵니다 (시드 난수).
- 관리자는 보드에서 주제를 직접 골라 다음 주차를 미리 만들 수도 있습니다.

## 문제 수집

- **LeetCode** — 공개 GraphQL API에서 목록을 가져옵니다. 유료(Premium) 문제와 커리큘럼 주제에
  매칭되지 않는 문제는 제외. 약 600문제.
- **프로그래머스** — 문제 목록 API가 로그인 없이 열려 있지 않아, `data/programmers-seed.json`에
  큐레이션한 문제 ID 68개(고득점 Kit 중심)를 쓰고 제목만 실제 문제 페이지에서 확인합니다.
  문제를 추가하려면 이 파일에 `{ "id": 레슨번호, "topic": "주제slug", "level": 1~5 }`를 넣고
  다시 수집하면 됩니다.
- LeetCode 스터디 플랜(Top Interview 150, LeetCode 75, DP, Graph Theory, Binary Search)에
  포함된 문제는 `featured`로 표시되고, **주차 문제는 이 중에서 우선 선정**됩니다.
- 관리자는 보드의 "문제 다시 수집" 버튼으로도 갱신할 수 있습니다.

## 보드

- 3열 칸반: **풀 문제 / 푸는 중 / 푼 문제**. 내 카드는 드래그 또는 버튼으로 이동합니다.
- **스터디원 카드가 모두 보입니다.** 한 문제당 멤버 수만큼 카드가 생기므로 누가 어디까지 갔는지
  한눈에 보입니다. 혼자 볼 때는 멤버 필터를 "나만"으로 두면 됩니다.
- 필터: 주차(이번 주 / 특정 주차 / 전체) · 난이도(쉬움 / 보통 / 어려움) · 멤버(전체 / 나만 / 특정 멤버).
- 난이도는 출처가 달라도 3단계로 정규화됩니다 — Easy·Lv.1 / Medium·Lv.2~3 / Hard·Lv.4+.
  (카드에는 원래 표기인 `Medium`, `Lv.2`가 그대로 보입니다.)
- 상단에 멤버별 진행 현황(푼 문제 / 전체)이 표시됩니다.

## 풀이 작성 · 공유

카드의 **풀이 작성 / 풀이 보기** 버튼을 누르면 문제별 풀이 화면이 열립니다.

- **내 풀이** — 언어 선택(Python, JS, Java, C++, Go, Rust 등 14종) + 코드 + 설명 + 참고 링크.
  코드 입력창은 Tab 키로 들여쓰기가 되고, 입력을 멈추면 2초 뒤 자동 저장됩니다.
  설명에는 접근 방법 · 시간복잡도 · 막혔던 부분을 적으면 됩니다. 상태도 여기서 바꿀 수 있습니다.
- **스터디원 풀이** — 같은 문제를 푼 다른 멤버의 코드와 설명을 전부 볼 수 있습니다.
  실수로 스포일러를 보지 않도록 기본은 접혀 있고, 이름을 클릭하면 펼쳐집니다.
  코드는 복사 버튼으로 바로 가져올 수 있습니다.
- 읽기는 전원 공개, **쓰기는 본인 카드만** 가능합니다.

## 구조

```
server.js               HTTP 서버 · 정적 파일 · 쿠키 세션
src/db.js               스키마 (users / problems / weeks / week_problems / assignments)
src/auth.js             scrypt 해시 · 세션
src/api.js              REST 핸들러 + 권한 체크
src/collect.js          LeetCode / 프로그래머스 수집기
src/rotation.js         ISO 주차 계산 · 주제 순환 · 문제 선정
src/topics.js           알고리즘 커리큘럼 20개 + LeetCode 태그 매핑
data/programmers-seed.json  프로그래머스 큐레이션 문제 목록
public/                 프론트엔드 (바닐라 JS, 빌드 없음)
```

## 배포 메모

세션 쿠키에 `Secure` 플래그를 붙이지 않으므로, 공개 배포 시에는 HTTPS 리버스 프록시
(nginx / Caddy) 뒤에 두고 `server.js`의 `setSession`에 `Secure`를 추가하세요.
